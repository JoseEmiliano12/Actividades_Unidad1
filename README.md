# Actividades de la Unidad 1

Este repositorio reúne las actividades, prácticas y evidencias de la Unidad 1 de Inteligencia Artificial. Incluye documentos, programas en Python, notebooks y conjuntos de datos utilizados en los ejercicios.

## Contenido

- **01_configurar_entorno:** configuración del entorno de desarrollo y prueba de Python.
- **02_HIstoria_ia:** carpeta destinada a la actividad de historia de la inteligencia artificial.
- **03_lectura_analitica:** cuaderno de lectura analítica sobre la historia de la IA.
- **04_mapa_agentes:** mapa sobre agentes de inteligencia artificial.
- **05_limpieza_con_bash:** limpieza de datos y comandos utilizados en Bash.
- **06_bash-pibsatisfaccion:** preparación y combinación de datos de PIB y satisfacción.
- **07_logica-proposicional:** ejercicios de operadores y lógica proposicional en Python.
- **08_taller_crewai:** práctica de agentes con CrewAI, informes y noticias generadas.
- **09_talleres:** prácticas de redes neuronales, procesamiento del lenguaje natural, lógica difusa e imágenes para clasificación.
- **10_aprendizaje:** ejercicios de aprendizaje automático con árboles de decisión y conjuntos de datos.

Los archivos se conservan organizados por actividad. Para ejecutar los programas, se necesitan Python y las bibliotecas que utiliza cada práctica. Algunas rutas de datos pueden requerir ajustes al equipo donde se ejecuten.

No se incluyen claves de API, entornos virtuales, cachés ni registros de ejecución. La carpeta de historia de la IA se conserva con un archivo `.gitkeep` porque todavía no tiene actividades.
